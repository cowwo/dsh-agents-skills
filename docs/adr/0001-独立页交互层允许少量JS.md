# 0001 · 独立页交互层允许少量 JS

- 状态：已采纳
- 日期：2026-10-13
- 相关文件：`lib/page.js`、`client/page-ui.js`、`test/page.test.mjs`

## 背景（Context）

独立页（`/dsh-agents-skills`）最初是**零 JavaScript** 的服务端渲染：展开/折叠用原生
`<details>`，所有操作是 GET 链接 + POST 表单 + 303 重定向，状态编在 URL 里
（`?tab/repos/repo/todo/skills`、`?check`、`?todo=1`、`?pickall=1`、`pick=`、`back=`）。
配套的 CSP 是「禁止一切脚本」：`default-src 'none'; style-src 'unsafe-inline'; …`。

这样做的理由是：插件没有构建步骤，独立页要在没有聊天界面的情况下打开，零脚本就没有
脚本注入面，也没有「前端版本和宿主版本对不上」的问题。

**新痛点**：纯整页导航意味着每点一次按钮/链接都整页白闪；POST 回到页面后**丢了滚动位置**
（技能页真正的滚动条在 `.table-scroll` 里，不是 window）、**丢了折叠区的展开/收起状态**。
批量操作用起来尤其别扭。

## 决策（Decision）

加一层**薄 pjax**：新增 `client/page-ui.js`（≤200 行、vanilla、无依赖、无构建），由
`createPageHandler` 在 `GET <pagePath>?asset=page-ui.js` 时 serve（`text/javascript` +
`no-store`），页面 `<head>` 用
`<script src="<pagePath>?asset=page-ui.js" defer></script>` 外链引用（**不是内联**）。

- 拦截站内指向本页的 GET 链接：`fetch` → `pushState` → 用响应 HTML 替换 `<title>` 与
  `<body>` 全部内容 → 导航类滚到顶部。
- 拦截 POST 表单：提交按钮加 `.busy`（禁用 + 变淡防连点）→ 以
  `application/x-www-form-urlencoded` 提交 → 跟随 303 → `pushState` 最终 URL → 替换页面 →
  **保持原滚动位置**；失败先移除 `.busy`，再回退原生提交（`requestSubmit`，老浏览器补一个
  隐藏字段后 `form.submit()`，保证提交按钮的 `name/value` 不丢）。
- 替换前按 `<summary>` 文本记下哪些 `details.fold` 开着，替换后按文本重开。
- `popstate`（前进/后退）重新 fetch 当前 URL 替换。
- 选择器全部防御性写，结构对不上就静默退出，绝不抛错到控制台。

CSP 同步放宽到「刚好够用」：

```
default-src 'none'; script-src 'self'; connect-src 'self'; style-src 'unsafe-inline'; form-action 'self'; base-uri 'none'; frame-ancestors 'none'
```

## 约束（Constraints）

- ≤200 行、无依赖、无构建；不 eval、不动态建函数、不动态加载模块、不碰浏览器本地存储。
- SSR + 纯表单保留为无 JS 兜底：协议值（`row` / `batch` / `pick` / `subscribe`）一个字不改。
- **内联脚本仍然禁止**：`script-src 'self'` 不含 `'unsafe-inline'`，也不放 data:/blob:，
  只有本站自己 serve 的这一个外链文件能执行；页面产物里除这一个 `<script src defer>` 外
  不允许出现任何 script 标签、`javascript:` 链接或 `on*` 内联事件（测试盯着这条）。

## 后果（Consequences）

- **设置页 `client/client.js` 不受影响**：它本来就自带 React 与自己的构建/加载方式，
  这次改的是独立页与它自己的 CSP，两套东西不共享代码、不共享脚本来源。
- **攻击面变化与护栏**：从「无脚本」变成「只允许一个同源外链脚本」，多出来的是
  内联脚本注入（仍在 CSP 禁止之列）与 XSS 后可调用的 `fetch` 能力。护栏：`script-src 'self'`
  杜绝内联/外链第三方；`connect-src 'self'` 限定数据外发只能回本站；`form-action 'self'`、
  `base-uri 'none'`、`frame-ancestors 'none'` 维持原状；资产路由与页面共用同一道门禁
  （Host/Origin 栅栏 + 浏览器 cookie），拿不到 connection 服务时 fail closed。
- **无 JS 用户功能不降级**：每个操作都有服务端表单/链接的等价实现，折叠是原生 `<details>`，
  关掉 JS 只是回到整页刷新（白闪、丢滚动），功能一个不少。
